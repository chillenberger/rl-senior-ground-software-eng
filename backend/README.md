# Telemetry API 
This is the api for telemetry. 

## Getting Started
```bash
npm install 
npm run dev
```

or 

```bash
docker build -t telemetry-api .
docker run --rm -p 3000:3000 telemetry-api
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.


## Tests 

Run the test cases. `npm run test`
